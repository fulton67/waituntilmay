# /gillenwebsite covers

Written by `scripts/gillenwebsite/covers.mjs` (full data in `scripts/gillenwebsite/covers-report.json`). The lookup order is: Dylan's own artwork from dylansproduce.net when it is the largest file, then the iTunes Search API (`artworkUrl100` with 100x100bb changed to 3000x3000bb), then Cover Art Archive through a MusicBrainz release-group lookup, then Scrapling's stealth fetcher on Bandcamp and Apple Music web. Matches are on artist and title, and a remix, live or acoustic edition is never taken for the release itself. Each cover is saved at 2048×2048, quality 88, with 1080 and 512 copies.

# /gillenwebsite: where every component comes from

Every component on the three pages (`/gillenwebsite`, `/gillenwebsite/discography`, `/gillenwebsite/about`) has one row here.
Each row names the site it is modelled on, the pattern taken from that site, the file and line in the site's crawl, and exactly what is reproduced.
In code, each component carries a `SOURCES #nn` comment that points back to its row.

- Crawl folders for the 22 live sites are `~/arena/lexicon/channels/felixluke/<site>/deep/`.
- Crawl folders for the reference sites are `~/arena/lexicon/channels/references/<site>/deep/`.
- Script lines are given as `file:line` or `file:line:col`. Minified CSS sits on line 1.
- Pattern IDs (S1–S15, M1–M5, C1–C5, L1, K1) are from BRAND-BIBLE.md (ed8a2ea). Its R-rules are constraints, listed at the end, and none of them is the source for a row.

## Constraints (R-rules; never a source on their own)
- R1 white ground
- R2 one weight (400)
- R3 no shadows on DOM
- R4/R5 square, borderless controls, except where the source site draws a border (#08, #23, #24)
- R7 capitals typed, not transformed
- R9 most-used size 12px
- R10 under 10% of text at ≥40px
- R11 two faces (info + `--font-title`)
- R15 pinned header and stage
- R16 the credit (#31)
